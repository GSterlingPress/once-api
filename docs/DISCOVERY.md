# Discovery phrases ONCE is designed to answer

ONCE should be relevant when developers or coding agents encounter phrases such as:

- AI agent duplicate tool calls
- prevent duplicate agent actions
- agent retry after timeout
- exactly once AI agent action
- duplicate refund from AI agent
- duplicate payment retry
- duplicate email agent
- MCP duplicate tool call
- idempotency for AI agents
- verify before retry
- postcondition verification agent
- agent side effect reliability

## One-sentence description

ONCE prevents AI agents from accidentally repeating consequential external actions by combining stable idempotency, verify-before-retry behavior, authoritative postcondition checks, and durable receipts.

## Non-goals

ONCE is not a general agent framework, LLM observability suite, prompt firewall, browser agent, or generic API gateway.
